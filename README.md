# n8n으로 만드는 AI 업무 자동화

코딩 경험이 없어도 시작할 수 있는 n8n 워크플로우 자동화 실전서입니다.

n8n은 노드를 연결하는 방식으로 업무 흐름을 만드는 오픈소스 자동화 플랫폼입니다. 셀프호스팅으로 무료로 쓸 수 있고, 2026년 현재 AI 에이전트 노드와 MCP 연동을 기본으로 지원합니다. 이 책은 설치부터 워크플로우 기초, 데이터 다루기, 조건 분기와 반복, 스케줄링과 웹훅, LLM과 AI 에이전트 활용, RAG 파이프라인 구축, MCP 연동, 운영과 보안까지 처음부터 끝까지 다룹니다.

책의 마지막에는 웹훅으로 들어온 고객 문의를 AI 에이전트가 사내 문서(RAG)에서 답을 찾아 자동으로 응대하는 실전 프로젝트와 확인 문제 20문항, 상세 해설을 수록했습니다.

- 대상 독자: 자동화를 처음 접하는 비개발자부터, AI 파이프라인을 직접 구축하려는 개발자까지
- 기준일: 2026-10-09 (n8n은 업데이트가 빠르니 공식 문서를 함께 확인하세요)
- 구성: 첫 페이지, 책 소개, 전체 목차, Part 1~9 본문 20개 장, 실전 프로젝트, 확인 문제, 마무리
- 저장소: https://github.com/1130dlwltn2-sondol/n8n-ai-automation
