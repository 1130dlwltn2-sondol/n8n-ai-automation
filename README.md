# n8n으로 만드는 AI 업무 자동화

반복 업무를 줄이고 AI 응대 흐름을 직접 설계하고 싶은 분을 위한 n8n 입문→실전 안내서입니다. 노드를 연결하는 첫 워크플로우부터 API, AI 에이전트, RAG, MCP를 연결하는 과정과 운영 시 확인할 사항을 다룹니다.

## 대상 독자와 선수지식
- 자동화를 처음 접하는 비개발자, 업무 담당자, AI 파이프라인을 구축하려는 개발자
- 코딩 경험 없이 첫 워크플로우부터 시작할 수 있습니다. 실전 단계에서는 JSON·HTTP·API와 Docker의 기초를 함께 익히며 진행합니다.

## 학습 경로와 결과물
- 입문: n8n 이해, Docker·클라우드 설치, 첫 워크플로우 만들기
- 기초: 데이터·표현식, API 연동, 조건 분기·반복·병합, 에러 처리, 스케줄·웹훅
- 실전: LLM·AI 에이전트, 메모리·도구, RAG·벡터 검색, MCP 연동, 보안·모니터링·백업
- 만들어 볼 결과물: 문서 인덱싱, 고객 문의 응대, 실패 알림으로 나뉜 3개 워크플로우

## 본문 속 실전 프로젝트
Part 8의 ‘AI 고객문의 자동응대 시스템’에서는 홈페이지 문의를 웹훅으로 받아 사내 FAQ·제품 문서를 검색하고, 근거가 부족하면 담당자에게 전달하는 흐름을 설계합니다. 검색·응답·담당자 전달을 단계별로 시험하고, 운영 초기에는 사람이 답변 로그를 검토합니다. 실제 적용 전에는 사용 환경에 맞는 설정과 검증이 필요합니다.
