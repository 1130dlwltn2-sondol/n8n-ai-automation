# 31. 반복과 병합

아이템을 하나씩 처리하고 싶을 때는 Loop Over Items 노드를 씁니다. 예를 들어 고객 목록 100명에게 각각 다른 메시지를 보내는 경우입니다. Loop 노드는 아이템을 한 번에 하나씩(또는 지정한 묶음씩) 꺼내서 루프 안쪽 노드들을 실행합니다. 안쪽 처리가 끝나면 다음 아이템으로 넘어갑니다. 모든 아이템이 끝나면 루프를 빠져나와 done 가지로 이어집니다.

루프 안에서 주의할 점은, 루프 안쪽 노드들은 아이템 하나에 대해서만 동작한다는 것입니다. 전체 목록이 필요하면 루프 밖에 두어야 합니다. 또한 API 호출 제한이 있는 서비스에 루프를 돌리면 호출이 폭증할 수 있으니, Wait 노드로 간격을 두거나 배치 크기를 조절합니다.

여러 갈래의 데이터를 하나로 모을 때는 Merge 노드를 씁니다. 모드는 상황에 따라 고릅니다. Append는 두 입력을 순서대로 이어 붙입니다. Combine은 같은 키를 기준으로 합칩니다. 예를 들어 주문 목록과 고객 목록을 고객 ID로 합치는 식입니다.

Aggregate 노드는 여러 아이템을 하나의 아이템으로 뭉칩니다. 루프로 처리한 결과를 마지막에 하나의 보고서로 만들 때 씁니다. 예를 들어 100건의 처리 결과를 하나의 텍스트로 합쳐 슬랙에 한 번만 보내는 식입니다.

실습: 목록 반복 처리
1. Set 노드로 고객 5명의 목록 만들기
2. Loop Over Items로 한 명씩 메시지 텍스트 생성하기
3. Aggregate로 결과를 하나로 모아 출력하기

핵심 정리
- Loop Over Items는 아이템을 하나씩 꺼내 반복 처리한다.
- Merge는 여러 입력을 합치고, Aggregate는 여러 아이템을 하나로 뭉친다.
- 외부 API를 반복 호출할 때는 호출 제한을 고려한다.
