# Part 7. MCP 연동

## 70. n8n을 MCP 서버로 공개하기

MCP는 AI 모델이 외부 도구를 쓸 수 있게 하는 공개 표준입니다. n8n은 MCP 서버로 동작할 수 있어서, n8n의 워크플로우를 Claude 같은 AI 도구의 도구로 공개할 수 있습니다.

구조는 이렇습니다. n8n에 MCP Server Trigger 노드를 놓습니다. 이 노드가 MCP 서버의 입구가 됩니다. 그 뒤에 실제 일을 하는 워크플로우를 연결합니다. 예를 들어 "사내 휴가 잔여일 조회" 워크플로우를 MCP 서버로 공개하면, Claude에서 "내 휴가 며칠 남았어?"라고 물었을 때 n8n 워크플로우가 실행되어 답을 돌려줍니다.

연결 방법은 사용하는 AI 도구에 따라 다릅니다. Claude Desktop은 설정 파일에 MCP 서버 주소를 등록합니다. Claude Code는 claude mcp add 명령으로 추가합니다. 공식 문서에 도구별 연결 예제가 정리되어 있으니 그대로 따라 하면 됩니다.

반대 방향도 가능합니다. n8n의 AI 에이전트 노드에서 외부 MCP 서버를 도구로 쓰는 것입니다. MCP Client 노드로 외부 MCP 서버에 연결하면, 그 서버가 제공하는 도구들을 에이전트가 쓸 수 있습니다. 예를 들어 외부 MCP 서버의 검색 도구를 n8n 에이전트에 붙이는 식입니다.

MCP로 공개할 때는 보안을 신경 씁니다. 외부에 공개되는 만큼 인증을 걸고, 공개하는 워크플로우는 읽기 전용이나 제한된 기능으로 만듭니다. 민감한 작업은 MCP로 노출하지 않는 것이 원칙입니다.

실습: MCP 서버 공개
1. MCP Server Trigger로 시작하는 간단한 워크플로우 만들기
2. 공식 문서의 예제를 따라 AI 도구에서 연결하기
3. AI 도구에서 호출해 보기

핵심 정리
- n8n을 MCP 서버로 공개하면 AI 도구의 도구가 된다.
- MCP Client로는 외부 MCP 서버의 도구를 n8n 에이전트에 붙인다.
- 공개 범위는 최소로, 인증은 필수다.
