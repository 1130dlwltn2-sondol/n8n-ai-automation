# Part 3. 흐름 제어

## 30. 조건 분기

조건에 따라 다른 일을 하고 싶을 때는 분기 노드를 씁니다. 가장 기본은 IF 노드입니다. 조건식을 하나 정하고, 참이면 위쪽(true) 가지로, 거짓이면 아래쪽(false) 가지로 흘러갑니다.

예를 들어 주문 금액이 5만 원 이상이면 VIP 안내를 보내고, 아니면 일반 안내를 보내는 흐름을 만듭니다. IF 노드의 조건에 {{ $json.amount }} >= 50000 을 넣습니다. true 가지에는 VIP용 Slack 노드를, false 가지에는 일반용 Slack 노드를 연결합니다. 실행해 보면 금액에 따라 다른 가지가 활성화되는 것을 볼 수 있습니다.

경우가 세 가지 이상이면 Switch 노드가 편합니다. 조건을 여러 개 나열하고, 각 조건에 맞는 출력 가지가 생깁니다. 예를 들어 문의 유형이 "배송", "환불", "기타"일 때 각각 다른 처리를 하는 식입니다. 어느 조건에도 안 맞는 경우를 위한 fallback 가지도 만들 수 있습니다.

Filter 노드는 조건에 맞는 아이템만 남기고 나머지를 버립니다. 분기가 아니라 걸러내기입니다. 대량 데이터에서 조건을 만족하는 것만 다음 단계로 넘길 때 씁니다.

분기 노드를 쓸 때 주의할 점은 두 가지입니다. 첫째, 조건식의 데이터 타입입니다. 문자열 "50000"과 숫자 50000은 다릅니다. 비교가 이상하게 동작하면 타입을 먼저 의심하세요. 둘째, 가지가 합쳐지는 지점입니다. 분기된 흐름을 다시 하나로 모으려면 Merge 노드나 뒤에서 설명할 방식으로 합칩니다.

실습: 금액별 분기
1. Set 노드로 테스트 주문 데이터 3건 만들기
2. IF 노드로 5만 원 기준 분기하기
3. 각 가지 끝에 다른 메시지를 출력하는 노드 연결하기

핵심 정리
- IF는 참/거짓 두 갈래, Switch는 여러 갈래 분기다.
- Filter는 조건에 맞는 아이템만 남기는 걸러내기다.
- 조건식의 데이터 타입을 확인하는 습관이 중요하다.
