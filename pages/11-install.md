# 11. 설치하기: Docker와 클라우드

n8n을 시작하는 방법은 두 가지입니다. 직접 서버에 설치하는 셀프호스팅과, n8n에서 운영하는 클라우드를 쓰는 방법입니다.

셀프호스팅은 Docker로 설치하는 것이 가장 간단합니다. Docker가 설치된 컴퓨터에서 다음 명령을 실행합니다.

docker run -d --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n n8nio/n8n

브라우저에서 http://localhost:5678 에 접속하면 n8n 화면이 열립니다. 처음에는 관리자 계정을 만듭니다. -v 옵션으로 데이터 폴더를 볼륨에 연결해 두면, 컨테이너를 지워도 워크플로우가 사라지지 않습니다.

조금 더 제대로 운영하려면 Docker Compose를 씁니다. 데이터베이스를 PostgreSQL로 바꾸고, 환경 변수로 기본 설정을 넣어 둘 수 있습니다. 공식 문서의 Docker Compose 예제를 복사해 쓰면 됩니다. HTTPS 적용은 리버스 프록시를 앞에 두는 방식이 일반적입니다. 웹훅을 외부에 공개하려면 HTTPS가 필요하니, 실제 서비스용이라면 처음부터 적용해 두는 것이 좋습니다.

서버 관리가 부담스럽다면 n8n 클라우드를 씁니다. n8n.io에서 계정을 만들고 무료 체험을 시작하면 바로 에디터가 열립니다. 업데이트와 백업을 n8n이 대신해주니, 자동화 만드는 일에만 집중할 수 있습니다. 단, 실행량에 따라 요금이 붙는 구독형이므로, 자주 실행되는 워크플로우가 많다면 셀프호스팅과 비용을 비교해 보세요.

실습 환경 선택 가이드
- 공부용, 가볍게: n8n 클라우드 무료 체험
- 장기 운영, 실행량 많음: Docker 셀프호스팅
- 회사 내부망 전용: 사내 서버에 Docker 설치

핵심 정리
- Docker 한 줄 명령으로 로컬에 바로 설치할 수 있다.
- 데이터 볼륨을 연결해 두면 컨테이너를 지워도 워크플로우가 유지된다.
- 웹훅을 외부에 공개하려면 HTTPS가 필요하다.
- 클라우드는 편하지만 구독형이므로 실행량을 따져본다.
