# 책 소개

이 책은 n8n으로 업무 자동화를 시작하려는 사람을 위한 실전서입니다. n8n은 화면에 노드를 놓고 선으로 연결하는 것만으로 업무 흐름을 만드는 워크플로우 자동화 도구입니다. 코드를 몰라도 시작할 수 있고, 개발자라면 코드 노드로 어디까지든 확장할 수 있습니다.

n8n이 주목받는 이유는 세 가지입니다. 첫째, 오픈소스라서 직접 서버에 설치하면 무료로 무제한 실행할 수 있습니다. 자동화가 늘어날수록 요금이 늘어나는 구조가 아니라서, 실험을 많이 해볼수록 유리합니다. 둘째, AI 기능이 처음부터 설계에 들어 있습니다. LLM 노드와 AI 에이전트 노드가 기본 제공되고, 외부 AI 도구와 연결되는 MCP도 지원합니다. 셋째, 커뮤니티가 큽니다. 2026년 현재 GitHub 스타가 18만 개를 넘었고, 공유되는 워크플로우 템플릿이 수백 개 있습니다.

책의 구성은 다음과 같습니다. Part 1에서는 n8n이 무엇인지, 어떻게 설치하는지, 첫 워크플로우를 어떻게 만드는지 다룹니다. Part 2에서는 워크플로우의 기본 개념인 트리거와 노드, 데이터와 표현식, API 연동을 익힙니다. Part 3에서는 조건 분기와 반복, 에러 처리 같은 흐름 제어를 배웁니다. Part 4에서는 정해진 시간에 실행되는 스케줄과 외부에서 호출하는 웹훅을 다룹니다. Part 5에서는 LLM 노드와 AI 에이전트 노드, 메모리와 도구를 이용해 AI를 워크플로우에 붙이는 방법을 배웁니다. Part 6에서는 사내 문서를 검색해 답하는 RAG 파이프라인을 구축합니다. Part 7에서는 n8n을 MCP 서버로 공개해 Claude 같은 AI 도구와 연결하는 방법을 다룹니다. Part 8은 실전 프로젝트로, 고객 문의를 AI가 자동으로 응대하는 시스템을 처음부터 끝까지 만들어 봅니다. Part 9에서는 자격증명 관리와 보안, 모니터링과 백업 같은 운영 지식을 정리합니다.

각 장은 개념 설명, 따라 하기 실습, 핵심 정리로 구성됩니다. 실습은 n8n 클라우드 무료 체험이나 로컬 Docker 설치 중 편한 쪽으로 진행하면 됩니다. 예제 워크플로우 JSON은 저장소의 workflows 폴더에 정리해 두었습니다.

이 책을 다 읽고 나면, 반복되는 업무를 스스로 자동화하고, AI를 업무 흐름에 붙이고, 만든 자동화를 안전하게 운영하는 방법을 갖추게 됩니다.
