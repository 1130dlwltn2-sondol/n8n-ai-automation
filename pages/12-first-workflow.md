# 12. 첫 워크플로우 만들기

설치가 끝났다면 첫 워크플로우를 만들어 봅니다. 목표는 단순합니다. 버튼을 누르면 현재 시간을 가져와서 화면에 보여주는 흐름입니다.

n8n 에디터에서 New Workflow를 누릅니다. 빈 캔버스가 열리고, Add first step 버튼이 보입니다. 눌러서 Manual Trigger를 추가합니다. 수동 실행용 트리거로, 테스트할 때 가장 많이 씁니다.

다음으로 노드를 추가합니다. 캔버스에서 + 버튼을 누르고 Date & Time을 검색해 추가합니다. 앞 노드와 새 노드를 선으로 연결합니다. 연결은 노드 오른쪽의 점을 드래그해서 다음 노드 왼쪽 점에 놓으면 됩니다.

이제 Execute Workflow 버튼을 누릅니다. Manual Trigger가 실행되고, Date & Time 노드가 현재 시간을 계산해 결과를 보여줍니다. 노드를 클릭하면 입력과 출력이 JSON 형태로 표시됩니다. n8n의 모든 데이터는 이런 JSON 아이템의 목록으로 흐릅니다. 이 개념이 중요하니 꼭 확인해 두세요.

워크플로우를 저장하려면 Ctrl+S를 누르거나 Save 버튼을 누릅니다. 이름은 알아보기 쉽게 붙입니다. 예를 들어 "첫 워크플로우 - 현재 시간 표시" 같은 식입니다.

워크플로우는 기본적으로 비활성 상태입니다. 스케줄이나 웹훅으로 자동 실행되게 하려면 우측 상단의 Active 스위치를 켜야 합니다. 수동 실행만 할 거라면 꺼 두어도 됩니다.

실습: 인사말 워크플로우
1. Manual Trigger 추가
2. Set 노드(또는 Edit Fields)를 추가하고, 이름 필드에 "안녕하세요" 값을 넣기
3. 실행해서 출력 확인하기

핵심 정리
- Manual Trigger는 테스트용 시작 노드다.
- 노드는 + 버튼으로 추가하고 선으로 연결한다.
- 실행 결과는 JSON 아이템 형태로 노드마다 확인할 수 있다.
- 자동 실행을 원하면 Active 스위치를 켠다.
