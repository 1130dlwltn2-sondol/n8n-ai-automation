# Part 5. AI 기능

## 50. LLM 노드

n8n에 AI를 붙이는 가장 직접적인 방법은 LLM 노드입니다. 프롬프트를 넣으면 선택한 언어 모델이 답을 돌려줍니다.

먼저 모델 자격증명을 만듭니다. LLM 노드를 추가하고 Model 항목에서 사용할 모델을 고릅니다. OpenAI, Anthropic 등 주요 모델이 목록에 있습니다. 처음 연결할 때는 API 키를 입력해 Credential을 만듭니다. API 키는 Credentials에 안전하게 저장되니 노드에 직접 적지 마세요.

프롬프트는 표현식을 섞어 동적으로 만듭니다. 예를 들어 고객 문의 내용을 요약하는 노드라면, 프롬프트에 "다음 문의 내용을 한 줄로 요약하세요: {{ $json.inquiry }}" 라고 씁니다. 앞 노드에서 온 데이터가 프롬프트에 끼워져서 모델에게 전달됩니다.

출력 형식을 고정하고 싶다면 구조화 출력을 씁니다. JSON 스키마를 지정하면 모델이 정해진 형태의 JSON으로 답합니다. 뒤 노드에서 {{ $json.summary }} 처럼 필드로 바로 쓰기 편해집니다. 분류 작업처럼 결과가 프로그램적으로 쓰이는 경우에 유용합니다.

비용 관리도 생각해야 합니다. LLM 호출은 건당 과금되므로, 루프 안에서 대량 호출하면 요금이 늘어납니다. 테스트할 때는 작은 데이터로 먼저 돌리고, 운영에서는 호출량을 모니터링합니다. 간단한 분류나 요약은 작은 모델로도 충분한 경우가 많으니, 비싼 모델부터 쓰지 말고 작은 모델부터 시험해 보세요.

실습: 문의 요약
1. Set 노드로 테스트 문의 3건 만들기
2. LLM 노드로 각 문의를 한 줄 요약하기
3. 결과를 확인하기

핵심 정리
- LLM 노드는 프롬프트를 모델에 보내 답을 받는 노드다.
- API 키는 Credential로 저장한다.
- 구조화 출력으로 JSON 형태를 고정할 수 있다.
- 비용을 의식해 작은 모델부터 시험한다.
